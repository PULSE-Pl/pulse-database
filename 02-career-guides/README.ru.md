# 02. Гайды по карьере

Этот раздел посвящён профессиональному развитию в проектировании линейной инфраструктуры: переходу от учёбы к работе в индустрии, подготовке к техническим собеседованиям, инсайтам о международной релокации и дорожным картам получения профессиональной квалификации.

**Целевая аудитория:** студенты университетов и молодые инженеры, планирующие свой рост.
