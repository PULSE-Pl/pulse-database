# P.U.L.S.E.
**Public Utilities & Linear Structures Engineering**

Открытая международная база знаний и инженерии для специалистов по проектированию линейных сооружений и инженерных сетей.

## О платформе

**P.U.L.S.E.** объединяет структурированную отраслевую базу знаний, карьерные маршруты и инструменты инженерной автоматизации. Проект развивается как открытая, некоммерческая и политически нейтральная инициатива под лицензией MIT, призванная снизить барьеры входа в профессию для студентов, молодых специалистов и инженеров по всему миру.

## Структура базы знаний

* **[01. Обзор отрасли](01-industry-overview/README.md)** — классификации линейных объектов, международные нормативные системы (СП, AASHTO, DMRB, RTA), инженерные глоссарии и обзор транспортных и коммунальных сетей.
* **[02. Гайды по карьере](02-career-guides/README.md)** — дорожные карты развития в проектировании, требования к компетенциям, обзор ПО (Civil 3D, Topomatic Robur, OpenRoads) и подготовка к работе на международных рынках.
* **[03. Статьи и автоматизация](03-articles-automation/README.md)** — прикладные инженерные исследования, скрипты автоматизации (Python, Dynamo, AutoLISP, C#/.NET) и материалы журнала **P.U.L.S.E. Journal**.

## Участие и правила

Проект открыт для вклада инженеров, исследователей и студентов со всего мира. Перед отправкой материалов ознакомьтесь с [Уставом участников](CONTRIBUTING.md).
